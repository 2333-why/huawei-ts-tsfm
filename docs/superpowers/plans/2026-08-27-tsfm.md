# 时序基础模型迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `tsfm` 分支实现两个时序基础模型的 zero-shot、LoRA adapter、全量微调和最后一层训练，并用双 GPU 脚本覆盖两个数据集的 `48→1`、`96→4小时` 任务。

**Architecture:** 保留现有纯功率数据与评估契约，新增独立 foundation-model registry、后端适配层、参数冻结审计和 runner。批处理脚本只负责确定性展开 32 项矩阵与双卡调度，模型包保持懒加载以便测试不下载权重。

**Tech Stack:** Python 3.8.18、PyTorch 2.3、Transformers 4.46.2、PEFT 0.13.2、Pandas、PyArrow、PyYAML、Bash、pytest。

**Spec:** `docs/superpowers/specs/2026-08-27-tsfm-design.md`

## Global Constraints

- 使用解释器 `/opt/data/private/penv/time/bin/python` 和本地两张 GPU。
- 模型输入只能是历史归一化功率 `[B, seq_len, 1]`。
- 模型目录固定为 `Sundial`、`TimeMoE`；运行模式固定为 `zero_shot`、`adapter`、`full`、`last_layer`。
- 不允许导入 registry 或执行 `--list-models` 时下载权重。
- 训练模式必须审计真实可训练参数；审计失败即退出。
- 保留现有用户文件和无关改动，不修改 `/opt/data/private/code/Time-Series-Library`。
